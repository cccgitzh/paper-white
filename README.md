# 图片去底漂白 · paper-white

把扫描件 / 翻拍件发灰发黄的纸底洗成纯白、文字压成墨黑的**纯前端**工具。
带**透视裁剪**（斜拍文档拉直）和**打印**（页面尺寸 / 方向 / 边距）。

> 所有运算在浏览器本地完成，图片不上传任何服务器。

---

## 特性

| 模块 | 能力 |
|---|---|
| **去底** | 逐像素估计纸底亮度并归一化，灰黄纸底 → 纯白，墨迹不变形 |
| **漂白与加深** | 黑场 / 白场 / 锐化，独立控制文字深度与噪点压制 |
| **色彩模式** | 黑白文档（单通道） / 保留彩色（分通道白平衡，彩章不变色） |
| **倾斜纠正** | 自动识别文字行角度（±15°），也可手动微调 |
| **透视裁剪** | 四角 + 四边自由拖拽，斜拍文档四条纸边拉直成矩形，实时小窗预览 |
| **打印** | A4/A5/B5/Letter/自定义，纵横向、页边距、适应/铺满，带所见即所得的页面预览 |
| **输出** | PNG / JPG / WEBP，可调画质，按原始分辨率导出 |
| **体验** | 撤销重做、快捷键、拖拽/粘贴导入、参数自动记忆、移动端可用 |

## 快速开始

### 方式一：直接用（推荐给使用者）

```bash
# 双击打开即可，无需服务器、无需安装
open index.html          # macOS
start index.html         # Windows
```

或者用构建好的单文件版（发给别人最方便，一个文件搞定）：

```bash
npm run build            # 生成 dist/paper-white.html
```

### 方式二：本地开发

```bash
npm run dev              # 零依赖静态服务器 → http://localhost:5173
```

### 环境要求

- 现代浏览器（Chrome / Edge 90+、Safari 15+、Firefox 90+）
- Node.js 18+（仅构建与本地服务需要，使用功能本身不需要）

## 使用流程

1. **导入**：拖进窗口 / 点「打开图片」/ `Ctrl+V` 粘贴截图
2. **裁剪**（斜拍必做）：点「透视裁剪」，把四个角拖到纸的四个角上，右下角小窗会实时显示矫正结果，`Enter` 应用
3. **纠正倾斜**：点「自动纠正倾斜」（正拍的扫描件可跳过）
4. **调色**：拖「去底强度」和「黑场」直到纸底纯白、文字发黑
5. **输出**：保存为图片，或直接打印 / 另存为 PDF

## 设计约定

- **零依赖**：不引入任何框架与第三方库，`src/js/*.js` 用经典脚本按顺序加载，`file://` 直开可用。
- **单一数据源**：所有可调参数集中在 `DC.state`，UI 只是它的投影（`syncControls()`）。
- **渲染管线唯一**：预览与导出走同一条 `buildBase → warp → process` 管线，避免"预览好看、导出翻车"。
- **视觉令牌化**：颜色、间距、圆角全部走 `tokens.css` 变量，杜绝硬编码色值。

## 浏览器兼容与已知限制

- 透视裁剪的导出为逐像素重采样，4000 px 以上的大图导出约需 1–3 秒（有进度提示）。
- WEBP 导出依赖浏览器编码能力，不支持时自动回退 PNG。
- 打印依赖系统打印对话框，可选「另存为 PDF」；页眉页脚由浏览器控制，本项目通过 `@page { margin: 0 }` 抑制。
- 暂不支持：多图批量处理、自动文档边缘识别、画布缩放平移（见 [CHANGELOG](CHANGELOG.md) 的 Roadmap）。
