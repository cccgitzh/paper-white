# 功能说明

本文逐项定义每个功能的作用范围、可调参数与验收口径，作为改造与回归的依据。

---

## 1. 透视裁剪

### 范围

| 项 | 说明 |
|---|---|
| 编辑对象 | 旋转（含微调角度）后的整图，坐标系归一化到 `[0,1]²` |
| 手柄 | 4 个角点（自由拖拽）、4 条边中点（整条边平移）、框内任意处（整体平移） |
| 约束 | ① 角点必须落在图片范围内；② 拖拽后四边形必须保持凸（不允许自交）；③ 任意边不得短于对角线的 1.5% |
| 非法拖拽 | 直接丢弃该次位移，手柄停在最后一个合法位置，不弹窗、不打断操作 |
| 实时预览 | 右下角小窗同步显示「透视矫正 + 去底」后的结果，拖拽时每帧更新 |
| 应用 | 输出尺寸取对边平均长度，四条边被拉直为矩形（即"拉伸矫正"） |
| 退出 | `Enter` 应用 / `Esc` 取消并还原进入前的选框 / 工具条「重置」回到全图 |

### 与旧版的差异

旧版只能在屏幕上拖一个**矩形**框，斜拍文档裁完仍然是梯形的。
新版求单应矩阵后逐像素反查，梯形会被真正拉直成矩形。

### 验收口径

1. 把四角拖到斜拍文档的四个纸角上，应用后输出图中纸边与画布边平行（目视误差 < 2 px）。
2. 拖拽过程中任何时刻不出现自交四边形；把角拖到对角方向时界面不崩、选框不变形。
3. 取消裁剪后，输出与进入裁剪前逐像素一致。
4. 导出尺寸与预览窗口中的显示比例一致（同一份 quad，预览与导出的宽高比误差 ≤ 1 px）。

## 2. 打印

### 范围

| 项 | 说明 |
|---|---|
| 纸张 | A4 / A5 / B5 / Letter / 自定义（50–1000 mm，可分别设宽高） |
| 方向 | 自动（按能放得更大的方向选）/ 纵向 / 横向 |
| 页边距 | 0–30 mm，四边相同 |
| 缩放 | 适应页面（contain，可能留白）/ 铺满页面（cover，超出内容区的部分裁掉） |
| 预览 | 左栏按真实纸张比例绘制：白色纸面 + 虚线页边距 + 图片实际位置 + 底部信息（纸张/方向/边距/缩放百分比） |
| 输出 | 调用系统打印对话框，可选打印机或「另存为 PDF」 |

### 实现要点

- 预览与打印共用同一套 mm 计算（`computeLayout`），保证「看到的就是打出来的」。
- 打印时动态注入 `@page { size: Wmm Hmm; margin: 0 }`，并将图片按 mm 绝对定位到 `#printRoot`。
- 打印样式只保留 `#printRoot`，其余节点 `display:none`，避免工具栏/面板被打印出来。
- 铺满模式下图片被放进 `overflow:hidden` 的裁剪容器，图片坐标需减去容器原点（页边距），否则会整体偏移一个边距。

### 验收口径

1. 选择 A4 + 纵向，`@page` 输出 `size: 210mm 297mm`；切到横向后为 `size: 297mm 210mm`。
2. 页边距 10 mm 时，图片左边距 = 10 mm、可用宽度 = 纸张宽 − 20 mm。
3. 铺满模式下图片尺寸 ≥ 内容区尺寸，且被裁掉的部分不越出内容区。
4. 打印预览中的缩放百分比与实际图片宽度 / 内容区宽度一致。

## 3. 去底与漂白

| 参数 | 范围 | 作用 |
|---|---|---|
| 去底强度 | 0–100 | 0 保留原图，100 完全按纸底归一化；中间值线性混合 |
| 背景范围 | 3–30 % | 纸底估计的邻域半径。纸底不均匀时调大，字距密、图层复杂时调小 |
| 黑场 | 0–180 | 小于该亮度的像素压成纯黑，用于压死浅灰噪点 |
| 白场 | 180–255 | 大于该亮度的像素拉成纯白，用于洗白残留灰底 |
| 锐化 | 0–100 | 3×3 拉普拉斯锐化，增强文字边缘 |
| 模式 | 黑白 / 彩色 | 彩色模式对 R/G/B 分别估背景，等于自动白平衡 |

**验收**：示例图默认参数下，纸底区域 ≥ 95% 像素达到 255，正文笔画平均亮度 < 60。

---

## 4. 倾斜纠正

- 自动：在 ±12° 内以 0.5° 粗扫、0.25° 精修，取水平投影最锐利的角度，结果再取反施加到画布。
- 手动：滑块 ±15°，步长 0.1°。
- 几何变化（旋转 / 角度）会使既有裁剪框失效，此时自动清空裁剪框并提示。

**验收**：对已知 −2.2° 的测试图，自动识别结果与真值误差 ≤ 0.3°。

---

## 5. 输出

| 项 | 说明 |
|---|---|
| 格式 | PNG（无损，文档首选）/ JPG / WEBP |
| 画质 | 50–100，仅对 JPG / WEBP 生效 |
| 分辨率 | 始终按原图分辨率导出，与预览缩放无关 |
| 文件名 | `原文件名_去底.<扩展名>`，非法字符已过滤 |

**验收**：同一参数下导出图与预览图内容一致；三种格式均能产出可打开的合法文件。

---

## 6. 交互与状态

| 能力 | 说明 |
|---|---|
| 撤销 / 重做 | 40 步快照栈，覆盖参数、旋转、角度、裁剪框 |
| 参数记忆 | localStorage 保存去底参数与打印设置（不含图片） |
| 状态栏 | 显示文件名、输出尺寸、渲染耗时、当前模式；裁剪时显示「裁剪中」 |
| 提示 | 全部使用非阻塞 Toast，不再使用 `alert` |
| 导入 | 拖拽到画布 / 选择文件 / `Ctrl+V` 粘贴 |
| 移动端 | ≤900 px 时面板下沉为底部抽屉；≤640 px 时顶栏收起品牌文字、压缩按钮 |

---

## 7. 明确的非目标（本版不做）

| 项 | 原因 |
|---|---|
| 多图批量处理 | 需要队列、统一参数、打包下载，属于独立功能模块 |
| 自动文档边缘识别 | 需要边缘检测 + 直线拟合，误差控制成本高，且手动四角已够快 |
| 画布缩放 / 平移 | 会与裁剪拖拽的手势冲突，需重新设计交互模型 |
| PDF 多页输出 | 单图场景无需求，多页应通过系统打印对话框完成 |
